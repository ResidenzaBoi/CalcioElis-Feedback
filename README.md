Repository pubblica dedicata alla raccolta di **bug report**, **feedback**, **suggerimenti** e **richieste di nuove funzionalità** per CalcioElis.

CalcioElis è una piattaforma per la gestione di eventi sportivi, iscrizioni, squadre e risultati delle partite.

## 📝 Come inviare una segnalazione

Prima di aprire una nuova Issue, verifica che non esista già una segnalazione simile.

Quando possibile, includi:

- una descrizione chiara del problema o del suggerimento;
- i passaggi necessari per riprodurre il problema;
- la versione dell'applicazione utilizzata;
- il dispositivo, il sistema operativo e il browser;
- eventuali screenshot o video;
- il comportamento atteso e quello riscontrato.

Più informazioni fornisci, più sarà semplice analizzare la segnalazione.

## 🐞 Segnalare un bug

Per segnalare un malfunzionamento, apri una [nuova Issue](https://github.com/ResidenzaBoi/CalcioElis-Feedback/issues/new) spiegando:

1. cosa stavi cercando di fare;
2. cosa è successo;
3. come riprodurre il problema;
4. eventuali messaggi di errore visualizzati.

## 💡 Proporre una funzionalità

Hai un'idea per migliorare CalcioElis?

Apri una Issue descrivendo:

- quale funzionalità vorresti aggiungere o migliorare;
- quale problema risolverebbe;
- come immagini il suo funzionamento.

## 📦 Release e aggiornamenti

Le versioni pubblicate sono disponibili nella sezione [Releases](https://github.com/ResidenzaBoi/CalcioElis-Feedback/releases).

Le note di rilascio includono le principali:

- nuove funzionalità;
- correzioni di bug;
- migliorie grafiche e di usabilità;
- bug noti;
- modifiche tecniche rilevanti.

## 🗺️ Roadmap

La roadmap è indicativa e può cambiare in base ai feedback e alle priorità del progetto.

### ✅ Completato

- [x] Gestione degli eventi e del calendario
- [x] Iscrizione agli eventi
- [x] Gestione delle squadre
- [x] Gestione delle priorità di iscrizione
- [x] Classifica e statistiche dei giocatori
- [x] Aggiornamento manuale della PWA
- [x] Raccolta pubblica di bug report e feedback

### 🚧 In miglioramento

- [ ] Uniformare padding, spaziature e allineamenti tra le pagine
- [ ] Migliorare ulteriormente la responsività su dispositivi mobili
- [ ] Rendere più chiari gli stati degli eventi e delle iscrizioni
- [ ] Migliorare la documentazione delle funzionalità

### 🔜 Prossimi obiettivi

- [ ] Valutare nuove funzionalità sulla base delle Issue più richieste
- [ ] Migliorare l'esperienza utente nell'area amministrativa
- [ ] Aggiungere ulteriori strumenti per il monitoraggio delle partite e delle statistiche
- [ ] Definire una roadmap condivisa con priorità e scadenze

> Vuoi proporre un obiettivo per la roadmap? Apri una Issue descrivendo la tua idea.

## ⚠️ Bug noti

Alcune pagine potrebbero presentare ancora piccoli problemi di spaziatura, padding o allineamento degli elementi.

Se noti altri problemi di layout o visualizzazione, segnalali aprendo una [nuova Issue](https://github.com/ResidenzaBoi/CalcioElis-Feedback/issues/new).

## 🤝 Contribuire

Per contribuire al miglioramento di CalcioElis:

1. controlla le Issue già aperte;
2. apri una nuova Issue per una segnalazione o una proposta;
3. descrivi il problema o il suggerimento nel modo più dettagliato possibile;
4. partecipa alla discussione fornendo ulteriori informazioni, se necessario.

## 📌 Stato del progetto

CalcioElis è in sviluppo attivo. Alcune funzionalità potrebbero essere ancora in fase di miglioramento e l'interfaccia potrebbe subire modifiche nelle prossime versioni.

Grazie a tutti coloro che contribuiscono con segnalazioni, idee e feedback! ❤️
